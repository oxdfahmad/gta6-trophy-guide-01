**Vice City Trophy Ledger** — an offline guide and progress tracker for all 55 PS5 trophies in Grand Theft Auto VI.

Tick trophies off as you earn them; your checklist is saved in the browser, so you can close the tab and pick up where you left off. Export your progress to a file to back it up or move it to another machine, and import it back whenever you need it.

What is inside:

- **All 55 trophies** — every trophy from the official list, verified against Exophase and PSNProfiles, with its name, description, rarity tier, and how to unlock it.
- **Checklist that remembers** — progress is stored locally in your browser, no account and no server.
- **Export / import** — save your checklist as a file and restore it anywhere.
- **Filters** — narrow the list by status (earned / remaining), rarity, or category to find what is left.
- **Spoiler setting** — hide trophy descriptions until you choose to reveal them, so story moments stay unspoiled.
- **Platinum roadmap** — a 6-phase plan that orders the trophies into a sensible route to the platinum.
- **Missable trophies page** — a dedicated page listing every trophy you can permanently miss, so you can grab them before they are gone.

Everything runs fully offline in the browser — no network calls, no tracking, no account.

## Run it

```bash
node serve.ts
```

Then open http://localhost:8080 in your browser.

Prefer no server at all? Open `app/index.html` directly in desktop Chrome — the guide works as a plain local file too.
